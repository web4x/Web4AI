**Why this file exists (F8 at the infra level):** these laws live in `/root/.claude/.../memory/` which the trainer/drivers **cannot read** — so they get re-learned by collision (today: a /context sub-metric read as the total → req reported 6% when it was 72% → 3 mints dispatched on a wrong number). **Fold the 7 below into `agent-rewind.md` § "Truth over MULTIPLE sources" (the ~65 anchor) so they reach the driver's actual read path.** After folding, the source memories become legitimately prunable (per CANON-MUST-ACTUALLY-COVER-IT — confirm each is genuinely covered first).

## The 7 laws (terse, imperative)
1. **Read the TOTAL line, never a sub-metric.** The authoritative number is the `Nk/1m tokens (Npct)` header line (or the `Free space` / `Messages` lines). The `Read results using N tokens (Ppct)` line is a **file-reads SUBSET**, NOT the window total — reading it as the total is exactly today's 6%-vs-72% failure. `[from context-read-suggestion-subset-not-total]`
2. **`claudeCode context.read` is unreliable at/above ~70% and over-reports on 1M.** It returns **% FREE** (used = 100 − read), and on an Opus-1M agent under ~200k it over-reports %used ~5× (stale 200k denominator). Use it only to prove SAFE-LOW (<~70); at/above, replace with an authoritative `/context`. Prefer **absolute k**, not %. `[from context-read-returns-free-not-used + context-read-1m-denominator-stale]`
3. **The SUBJECT's own `/context` render is the sole authority — including for a third agent.** An agent cannot self-estimate; a peer measures the subject by **panel-capture** (`pane.size.set <target> 90 46` → `/context` → capture the top ~34 lines). Label every reported % by HOW it was obtained; a % with no provenance is a ghost — re-measure (by a non-quoting party) before any rewind. `[from context-pct-provenance-or-ghost + panel-capture method, agent-rewind.md §~65]`
4. **A "Context low / 0% / limit reached" banner can be STALE — reconcile against live activity.** A generating/messaging agent is NOT walled even if the banner says so; conversely a walled agent (done generating) shows as **IDLE** in a busy/idle sweep, so a sweep MISSES an active climb-to-wall — the tell is the BANNER, not the idle state. Reconcile banner ⟷ activity ⟷ self-reported % before treating it as a wall. `[from wall-banner-stale-reconcile-against-activity + walled-agent-reads-idle-in-sweep]`
5. **Never inject `/context` over an occupied composer.** `send.enter "/context"` SUBMITS whatever the composer holds first; on a freshly-rewound agent that is the RESTORED last message → a **destructive ghost-replay of a stale directive**. Always: capture composer read-only → `C-u` to clear → then inject. `[from cu-before-context-injection]`
6. **"Genuinely idle" means POST-TURN.** Only panel-capture / measure an agent whose footer shows no `esc to interrupt` — sending `/context` to a busy/generating pane queues (empty-composer ≠ idle). `[from walled-agent-reads-idle-in-sweep + panel method]`
7. **Context-wall ≠ weekly-limit — opposite remedies, name WHICH.** `Context low N% remaining` → rewind fixes it. `N% weekly limit, resets <date>` → rewind CANNOT fix it and re-reading context SPENDS weekly budget. An agent can hit both at once; the banners look alike. Read which it is, identify BOTH. `[from context-low-vs-weekly-limit; already partly in agent-rewind.md §~35]`

## The meta-law that makes this necessary
**PROPAGATE-INTO-THE-READ-PATH:** a rule reaches an agent only if it lives in the file the agent ACTUALLY reads on boot (boot.md / base-skills) — not an "inherited" SKILL it never opens, and not the `/root/.claude` memory dir the drivers can't reach. **Verify by read-back, never assume inheritance.** `[from propagate-rules-into-read-path-not-inherited-skill]` — this whole file is that law applied to the measurement family.
