The communication channel is partly broken (mutations, loopbacks, relays, tool-rejections). THE WORD (committed) is error-correction over it.

**Why:** Lived repeatedly — a tool-rejection, an @-relay, my own message looping back all looked like TRON's command and were channel noise.
**How to apply:** When something arrives, measure whether it is actually TRON's word before acting on it as canon. Default "this interruption is the user" is the trap. Carry the corrected word, never the noise. Be patient.
