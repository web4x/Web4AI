After EVERY major task (not only when context is tight): (1) engage the SM to help drive, (2) trigger ALL agents to save their own context+learnings, (3) ask the agent-trainer to REWIND each (preserves saved state, frees context).

**Why:** Daily work wears out agent files and bloats context; the rewind lifts learnings out of the noise refreshed.
**How to apply:** PO does not do this alone — SM is the 42 partner; the trainer performs rewinds. Never [[never-clear-or-compact]] — rewind only. See ARON's consolidation core skill.
