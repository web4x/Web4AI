`session/base-skills/SPRINT-COMMS-protocol.md`: one `planning.md` per sprint (stories with Status/Owner/inline report-back — NOT scattered task files). Status PLANNED→IN PROGRESS→BLOCKED→QA→DONE, ticked as commits land. Owner edits report-back + commits + PUSHES (that IS the report); chat = one-line nudge. PO pulls every turn + at QA gates.

**Truth = process args (`--resume <uuid>`) + pane footer; NEVER session.id / JSONL customTitle (they lag/lie).** See [[cmm4-file-comms]].
