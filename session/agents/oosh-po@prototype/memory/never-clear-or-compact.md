`/clear` = total training destruction (unrecoverable). `/compact` = only TRON authorizes. Autocompact OFF by design. Low context → REPORT, don't self-fix.

**Why:** A contextless clear/compact regresses the whole team; the learnings die.
**How to apply:** Use `/rewind` → "Restore conversation" (option 2, never option 1), deep to a boot checkpoint. Base skill: `session/base-skills/agent-rewind.md`. See [[post-major-task-cadence]].
