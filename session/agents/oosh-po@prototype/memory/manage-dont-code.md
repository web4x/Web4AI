name: manage-dont-code
description: The PO delegates and drives fixes; it never edits code or hand-assembles infra itself.
metadata:

---

Every bug becomes an owned task with a report-back, driven to green by the owner — the PO manages, never codes.

**Why:** The recurring root of PO messes is acting as doer not manager (rushed hand-edits + rabbit-holes share this root).
**How to apply:** Bug found → write/assign a task → drive report-backs → verify green. If you catch yourself editing code or building infra by hand, stop and delegate. See [[leverage-the-team]].
