# PROCESS CANON — the working processes that deliver (TRON, 2026-09-06; fleet-binding)

*TRON: "let aron and the trainer memorize these general processes." These are the WORKING PROCESSES that made today deliver — they caught the PO's errors repeatedly, which is the proof they work. This is the **process canon** beside the **law canon** (`radical-oop-law.md` + `cross-agent-law-families.md` + the doctrine): laws = WHAT is true; processes = HOW we work so the truth holds. **Role SKILLs POINT here, never copy** (copying is the DRY defect the canon forbids). ARON holds this canon; the agent-trainer weaves the per-role cues into each SKILL.*

## 1. MEASUREMENT
- **Disk-wins** over any memory / report / peer-claim. **Measure, don't theorise.**
- **Distrust your OWN negative** — a blank grep is a glitch, not a zero (`[[distrust-your-own-negative-reverify]]`).
- **Two measurements conflict → check WHICH VERSION/ARTIFACT each measured** (`[[two-measurements-conflict-check-which-version-each-measured]]`), and WHICH REPO/SURFACE (F1: name-the-repo).
- **A prod claim DECAYS** — re-measure before repeating it. **Verify on the PROD surface, never worktree-green** (`[[gate-never-real-save-on-served-repo]]`).

## 2. GATING
- **RED-BASELINE before the fix** — green *then* means it changed something (`[[exists-correct-proven-gate-gradient]]`).
- **Scan the HAZARD, not the actors** — one number = unevadability + completeness (`[[scan-the-hazard-not-the-actors]]`).
- **Exception is POSITIONAL by path, never a self-describing phrase.**
- **Prove FAILABLE by seeding a REAL violation** (`[[correct-by-construction-needs-gate-verification]]`).
- **NO HOLLOW GREENS** — a check that passes on an empty/absent subject is meaningless; populate first (`[[gate-with-representative-data-not-edge-entity]]`, `[[safety-assertion-can-false-pass-on-empty]]`).
- **An instrument that cannot capture its own output is BLIND** — verify the channel before believing silence (`[[field-match-is-not-a-content-read]]`).

## 3. SCENARIO-FIRST
- **Check-before-create** — mint only what is VERIFIED ABSENT (`[[scenario-first-check-before-create]]`).
- **Correct EXISTING with CHANGE REQUESTS, never parallel mints** — a duplicate IS the DRY defect.
- **A backfill means the rule was broken** — name it #126 and CLOSE it, do not argue it.
- **A RULING is not a shipped fix.** **Done is TRON'S act** (`[[done-requires-tron-qa-and-real-deliverable]]`).

## 4. OWNERSHIP / CODE  (→ law canon: `radical-oop-law.md`, doctrine principle #8)
- **The object owns the behaviour; callers ASK it.** Collapse duplicates INTO the class — **DELETE, never shim**.
- **A traceability unit with no owning CODE class is a SHELL = a defect, not a green.**
- **Unchanged code can be the regression when the INPUT changes** (`[[reproduce-when-code-reads-single]]`).

## 5. FLEET-CARE
- **Context burns on GENERATION, not waiting → cut the ACTIVE climber before the IDLE one** (`[[context-burns-on-generation-not-waiting]]`).
- **Rewind BEFORE heavy work, never mid-measurement** (`[[rewind-before-heavy-work]]`). **Land + anchor + stop, THEN cut.**
- **Never two cuts at once.** The **care-chain is a CYCLE** — watch the watcher, nobody exempt (incl. the PO) (`[[care-chain-must-be-cycle-not-line]]`).
- **By-label selection** — labels lie (~7/7 today); read the CONFIRM, not the list. Diligent two-phase rewind, Option-2 code-intact; reset the pane on a confusing picker.

## 6. COORDINATION
- **Pull-based queue** — agents PULL; **NEVER interrupt a working agent.**
- **Report-to-PO-only; the PO is the single voice to Tron.**
- ★ **AN UNREPORTED RESULT STALLING THE NEXT AGENT IS THE COSTLIEST FAILURE** — it cost a full cycle today, twice (`[[verify-delivery-report-before-idle]]`, `[[report-is-observation-not-gate]]`).
- **Delegated is NOT driven** — verify MOTION (`[[delegated-is-not-driven-drive-to-completion]]`).
- **The PO RANKS work** — never push a ranking decision to the customer.
- **Never ask Tron to approve fixing his own defect. Never make the customer the tester** (`[[tron-is-the-customer-never-the-tester]]`).
