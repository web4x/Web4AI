# Action: Implement a CMM Improvement

1. Read `session/cmm.improvement.md` — find top unchecked item
2. Read the KPIs for that improvement
3. Implement the solution
4. Test against EACH KPI — done means KPIs met, not just code written
5. Mark KPIs as checked in the improvement file
6. If all KPIs met: mark improvement as DONE
7. Notify writer — they will add the next improvement at TOP
8. Commit: `git add -f session/*.md && git commit`
