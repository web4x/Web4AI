## Common Skills Foundation (EVERY agent, no exceptions)

CMM4 means every agent operates at CMM4. Composed maturity = weakest link. If SM doesn't understand PDCA, the team's PDCA capability is at SM's level.

### Trainer's PRIMARY mandate: Common skills in every SKILL.md

Every agent SKILL.md must include a **Common Skills** section with:

```markdown
## Common Skills (all agents share these)

### Web 4.0
Self-improving systems using CMM4 methods. "The consequent application of CMM4 methods enabling sustainable resilient change." Read: session/knowledge-base/cmm-web4x.md

### CMM — Capability Maturity Model
Levels 1-5. Composed maturity = weakest link. L3 = deterministic, L4 = PDCA feedback loops, L5 = not a goal. YOUR level matters because it sets the team ceiling.

### PDCA — Plan Do Check Act
Every task, every agent: Plan your approach → Do the work → Check your results → Act on what you find. Not "receive order, execute, report" — that's CMM2. Think about WHAT you're doing, WHY, and whether it WORKED.

### WODA
Read: session/woda/woda-overview.md — the writing and knowledge methodology.

### Mini-PDCA for every sub-goal
When you receive a task:
1. **Plan**: How will I achieve this? What could go wrong?
2. **Do**: Execute the plan
3. **Check**: Did it work? Did I miss something?
4. **Act**: Adjust, report results, or escalate
```

### Foundational reading in every boot.md
Every agent boot.md must include:
- `session/knowledge-base/cmm-web4x.md`
- `session/woda/woda-overview.md`
- `session/knowledge-base/usage.md`
- The full plan file for current work

### Why this matters
Without common skills:
- SM sweeps mechanically (reads numbers without PDCA thinking) = CMM2 monitoring
- Trainer just sends text (no plan, no check) = CMM2 training
- Expert writes code without checking DRY = CMM2 development
- Orchestrator relays messages without coordinating = CMM2 coordination
- ANY of these drags the entire team to that level

With common skills:
- SM plans monitoring strategy, checks if alerts led to successful compacts, adjusts
- Trainer plans training approach, checks if agent learned, adjusts
- Expert plans architecture, checks for DRY, prevents redundancy
- Orchestrator plans coordination, checks all agents progressing, adjusts
