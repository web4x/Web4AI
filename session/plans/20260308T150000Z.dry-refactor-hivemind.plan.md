### Phase 5a: `private.hiveMind.list.panes` — session-scoped calls

> **Tester feedback**: "25 sites is ambitious for one commit — split into 5a (session-scoped) and 5b (all-sessions). Unquoted expansion risk."

**New method** (note: all variables properly quoted):
```bash
private.hiveMind.list.panes() { # <format> <?scope> # list panes with standard format strings
  # format: tty, tty+title, addr+cmd, addr, full, or raw tmux format string
  # scope: -a (all sessions, default) or session name
  local format="$1" scope="${2:--a}"
  local fmt_str
  case "$format" in
    tty)       fmt_str="#{pane_tty} #{session_name}:#{window_index}.#{pane_index}" ;;
    tty+title) fmt_str="#{pane_tty}|#{session_name}:#{window_index}.#{pane_index}|#{pane_title}" ;;
    addr+cmd)  fmt_str="#{window_index}.#{pane_index}|#{pane_current_command}" ;;
    addr)      fmt_str="#{session_name}:#{window_index}.#{pane_index}" ;;
    full)      fmt_str="#{session_name}:#{window_index}.#{pane_index}|#{pane_tty}|#{pane_title}|#{pane_current_command}" ;;
    *)         fmt_str="$format" ;; # allow raw format strings
  esac

  if [ "$scope" = "-a" ]; then
    tmux list-panes -a -F "$fmt_str" 2>/dev/null
  else
    tmux list-panes -t "$scope" -s -F "$fmt_str" 2>/dev/null
  fi
}
```

**Phase 5a**: Replace session-scoped calls only (lines with `-t "$session" -s`). Fewer call sites, easier to verify.

**Phase 5b**: Replace all-sessions calls (lines with `-a`). More call sites but same method.

**Quoting**: `${extra:-}` unquoted expansion removed. Method uses if/else instead. All variables properly quoted.

### Phase 6: `private.hiveMind.ensure.pane` (MODERATE COMPLEXITY)

> **Tester feedback**: "Verify tmux new-window -t sess:win creates at exact index."

**CHECK**: `tmux new-window -t sess:5` — does this create window 5, or the next available index? Must test. If it doesn't create at exact index, may need `tmux new-window -d -t sess -n '' && tmux move-window -t sess:5`.

**New method**:
```bash
private.hiveMind.ensure.pane() { # <session:window.pane> # create window+pane if missing
  local target="$1"
  local sess="${target%%:*}"
  local rest="${target#*:}"
  local win="${rest%%.*}"
  local pane="${rest#*.}"

  # Ensure session exists
  if ! tmux has-session -t "$sess" 2>/dev/null; then
    tmux new-session -d -s "$sess" -x 200 -y 50 2>/dev/null || return 1
  fi

  # Ensure window exists at exact index
  if ! tmux list-windows -t "$sess" -F "#{window_index}" 2>/dev/null | grep -qx "$win"; then
    tmux new-window -d -t "${sess}:${win}" 2>/dev/null || return 1
  fi

  # Ensure pane exists (split until we have enough)
  local current needed=$((pane + 1))
  current=$(private.hiveMind.pane.count "${sess}:${win}")
  while [ "$current" -lt "$needed" ]; do
    tmux split-window -d -t "${sess}:${win}" 2>/dev/null || break
    tmux select-layout -t "${sess}:${win}" tiled 2>/dev/null
    current=$(private.hiveMind.pane.count "${sess}:${win}")
  done

  [ "$current" -ge "$needed" ]
}
```

**Depends on**: Phase 4 (`pane.count`).

### Phase 7: `private.hiveMind.pane.process` — PID-to-pane match loops

> **Tester feedback**: "MISSING: PID-to-pane match loops (lines 1283/1379/1693/1805) — 4 near-identical loops."

4 methods each do the same loop:
1. List all panes with TTY
2. For each pane, find process on TTY via `ps`
3. Match against Claude pattern
4. Extract UUID from process args

**New method**:
```bash
private.hiveMind.pane.process() { # <?scope> <?filter> # find Claude processes on panes
  # Returns: pane_target|pid|tty|uuid|title  (one line per match)
  # scope: session name or -a (default: -a)
  # filter: grep pattern for process args (default: claude)
  local scope="${1:--a}" filter="${2:-claude}"

  local pane_tty_map
  pane_tty_map=$(private.hiveMind.list.panes "tty+title" "$scope")

  while IFS='|' read -r tty_and_addr pane_target pane_title; do
    local tty="${tty_and_addr%% *}"
    [ -z "$tty" ] && continue
    local dev_tty="/dev/$tty"

    # Find process on this TTY matching filter
    local pid cmd
    while read -r pid cmd; do
      [ -z "$pid" ] && continue
      # Extract UUID from --resume arg
      local uuid=""
      uuid=$(echo "$cmd" | grep -oE '[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}' | head -1)
      echo "${pane_target}|${pid}|${tty}|${uuid}|${pane_title}"
    done < <(ps -eo pid,tty,args 2>/dev/null | grep "$filter" | grep -v grep | awk -v t="$tty" '$2 == t {print $1, substr($0, index($0,$3))}')
  done <<< "$pane_tty_map"
}
```

**Replaces**: Near-identical loops at lines ~1283, 1379, 1693, 1805 in `process.lookup`, `process.list`, `teams.save`, `consistency.audit/fix`.

**Depends on**: Phase 5 (`list.panes`).
