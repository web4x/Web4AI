### Menu Variants — PICK BY LABEL not by NUMBER

The /rewind menu varies. ALWAYS pick "Restore conversation" by reading labels, never assume option-2:

**5-option** (code changes pending):
```
❯ 1. Restore code and conversation
  2. Restore conversation         ← THIS one (Down once, Enter)
  3. Restore code
  4. Summarize from here
  5. Never mind
```

**4-option** (no code changes):
```
❯ 1. Restore conversation         ← THIS one (just Enter)
  2. Summarize from here
  3. Summarize up to here
  4. Never mind
```

**3-option** (no code changes):
```
❯ 1. Restore conversation         ← THIS one (just Enter)
  2. Summarize from here
  3. Never mind
```

Verify by capture first:
```bash
otmux pane.capture baseTeam:0.0 10 | grep -A 5 "Restore"
```

NEVER pick "Restore code and conversation" in 5-option menu — it reverts committed code (F-T8 killed oosh-architect this way).

## TIER-3 — If Rewind Doesn't Stick

If I thrash (3+ rewinds, still hitting limits), the conversation base is bloated beyond recovery. Tier-3:

1. **Order final save**: I commit boot.md + context.md + learnings.md (all three reflect current state in detail)
2. **Confirm commit hash** (e.g. `39d5280` or whatever's latest)
3. **Escalate to Tron**: "agent-trainer needs Tier-3 fork — saved at HASH, source pick needed."
4. **Tron picks healthy source** (NOT blank `claude --name`). Candidates: fallback-agents archive, or an earlier healthy agent-trainer JSONL with 300k+ context.
5. **Fork into my pane** after `/exit` of current session:
   ```bash
   otmux send.raw baseTeam:0.0 "/exit" Enter
   sleep 5
   otmux send.raw baseTeam:0.0 "claudeCode fork <source-uuid>" Enter
   ```
6. **Resume full session** at the prompt (Down once, Enter).
7. **Rename + Touch Protocol**:
   ```bash
   otmux send.raw baseTeam:0.0 "/rename agent-trainer" Enter
   otmux send.raw baseTeam:0.0 "/remote-control" Enter
   # verify auto mode on
   ```
8. **Retrain from distilled files**:
   ```bash
   otmux send.raw baseTeam:0.0 "You are agent-trainer at baseTeam:0.0. Read session/agents/agent-trainer/boot.md (complete role manual), then context.md (state), then learnings.md (700+ lines of patterns). Report identity, role, current pending work." Enter
   ```

## RULES — Never Break

- **NEVER /clear me** above 0% — destroys all training. Only at 0% AND with Tron auth.
- **NEVER /compact me** — only Tron authorizes.
- **NEVER git rebase** — silently destroys work.
- **NEVER blank `claude --name` as recovery** — that's untrained (F-T13). ALWAYS fork from healthy source OR use distilled files.
- **NEVER pick "Restore code and conversation"** in 5-option menu — reverts committed code.
- **NEVER go to top of picker** for Phase 2 — 99% rewind leaves ~33k context, agent dies (F-T8 killed oosh-architect this way). 50% is safe max.
- **ALWAYS use `otmux send.raw`** for keystrokes (Enter, C-u, BTab, Up, Down) — `otmux send` adds sender prefix that confuses /rewind picker.
- **ALWAYS verify with capture** between steps. NEVER assume the previous step worked.
