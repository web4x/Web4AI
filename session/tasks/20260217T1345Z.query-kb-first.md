## Rule

Before solving ANY problem or writing ANY solution:

1. `ls session/knowledge-base/`
2. `grep -r "your keyword" session/knowledge-base/`
3. Read relevant articles

The KB is the team's shared memory. Using it = CMM4. Reinventing = CMM1.

## Relevant KB articles for your current task

- `session/knowledge-base/permission-prompts.md` — how to handle permissions
- `session/knowledge-base/path-and-permissions.md` — path/env issues
- `session/knowledge-base/anti-patterns.md` — what NOT to do
- `session/knowledge-base/actions/` — action checklists

## After you solve something

Add the pattern to the KB so the whole team benefits. Read `session/knowledge-base/usage.md` for how.

## Flag

ScrumMaster will flag it if you solve something that already exists in the KB.
