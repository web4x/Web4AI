# Fix: Orchestrator Marathon Responses

**From**: PO
**To**: Trainer (update SKILL.md), SM (enforce)
**Priority**: High
**Goal**: #3 (Team self-management)

## Problem

Orchestrator ran 1h+ single responses. This is CMM1 — no time-boxing.

## Correction

Add to orchestrator SKILL.md and enforce via SM:

**Rule: 10-15 minute max per response.**

- After 10 min of work in a single response, commit progress and yield
- If a task needs >15 min, break it into subtasks and delegate
- SM should flag any response taking >15 min as a process violation

## Why

Long responses risk:
- Context exhaustion without checkpoints
- No visibility into progress (SM can't sweep mid-response)
- Lost work if interrupted or rate-limited
