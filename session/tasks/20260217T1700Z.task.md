# Task: Fix hiveMind Parameter Naming — No Dashes in OOSH Identifiers

**Assigned to**: oosh-expert
**From**: Tron
**Priority**: HIGH

## Bug

`hiveMind peer.compact` crashes because the parameter name contains a dash:

```
PARAM_name-or-pane=addDefaultValue: not a valid identifier
```

Dashes (and underscores in certain positions) are not valid in bash variable names, which OOSH uses for `declare` in parameter handling.

## Root Cause

The method signature uses `<name-or-pane>` as a parameter name. OOSH converts this to `PARAM_name-or-pane` which is an invalid bash identifier.

## Fix

Audit ALL hiveMind methods for parameter names containing dashes. Rename them to valid identifiers (e.g., `nameOrPane`, `target`, `pane`). Common pattern:

- `<name-or-pane>` → `<target>` or `<nameOrPane>`
- Any other dashed parameter names → camelCase or single word

## Scope

- `/Users/donges/oosh/hiveMind` — search for parameter names with dashes
- Also check `scrumMaster`, `otmux`, `claudeCode` for the same pattern
- This is a naming convention rule: **OOSH parameter names must be valid bash identifiers (letters, numbers, underscores only, cannot start with a number)**
