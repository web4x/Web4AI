### Commands the orchestrator should know about:

```bash

hiveMind team.sweep projectTeam      # structured one-line-per-pane status
hiveMind sweep projectTeam           # full capture of all panes

# SM MONITORING (orchestrator's #1 job)
hiveMind monitor scrum-master 30     # capture SM pane output
hiveMind unblock scrum-master        # unblock if SM is stuck

# MESSAGING
hiveMind send.enter <name> "msg"     # send with Enter (replaces manual otmux send + Enter)
hiveMind broadcast "msg"             # send to ALL agents

# AGENT MANAGEMENT
hiveMind resolve <name>              # get pane address by role name
hiveMind agent.verify <name>         # check if agent is alive
hiveMind agent.bootstrap <role>      # full bootstrap: pane + claude + teach

# SUBSCRIPTION CHECK (before delegating — don't overload at 80%+)
scrumMaster subscription             # real-time subscription status
```
