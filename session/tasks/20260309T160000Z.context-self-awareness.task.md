# Task: Add claudeCode context.self for agent self-awareness

## W(hat)

Add a `claudeCode context.self` command that auto-detects the current pane via `$TMUX_PANE` and returns context %. Agents should be able to check their own context without knowing their pane address.

## O(verview)

| Item | What |

| New method | `claudeCode context.self` — returns context % for executing pane |
| Bug fix | `team.context.status` shows wrong role names and "NO-PANE" |
| Boot integration | All agents run `claudeCode context.self` on boot |

## D(etails)

### 1. `claudeCode context.self` (new method)

```bash
claudeCode.context.self() # # read own context % using TMUX_PANE
{
  local myPane
  myPane=$(otmux pane.get.target)
  if [ -z "$myPane" ]; then
    error.log "Not in a tmux pane"
    return 1
  fi
  claudeCode.context.read "$myPane"
}
```

No completion needed (no args).

### 3. Gaps in TUI context reading

`claudeCode context.read.tui` returns "unknown" when the agent is actively executing a Bash tool command. The pane shows command output instead of the Claude Code status bar. The JSONL method (`context.read`) works during execution — this is the right primary method. TUI should be fallback only.
