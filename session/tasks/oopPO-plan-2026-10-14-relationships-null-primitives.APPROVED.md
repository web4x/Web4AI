## Proposed answers to the open points (approve = accepted AS PROPOSED)
- **Q1 — non-primitive "attributes" that are machinery (Map/Set/WeakMap caches, `Promise`, private lazy state):** they are **not model attributes** — a private cache is behaviour-internal state, not part of the unit; they leave the Definition's `attributes` (stay as plain private fields in code, never in the model/diagram). Every **domain** non-primitive becomes a **relationship (0..1, `T | null`)** or **collection (0..n, `T[]`)**; a `Record`/`Map` of primitives is a collection.
- **Q2 — scope of "undefined is unwanted":** this plan removes `undefined` from **every relationship end** (model, all renderers, hand code) and from **every field the model generates**; private machinery fields leave the model (Q1) and get `| null` in the same pass. Parameters/return types (`string | undefined` as an optional input) are out of scope — a later hygiene item.
- **Q3 — the PUML plan's DONE:** independent. U4 finishes on `f41134102`; Tron rules that plan; this plan builds on top.

## Rules (the WHAT)
1. **Diagrams show type notation only:** `name: Type` — no `= initializer` on attributes or ends, ever. An untyped attribute shows the primitive type derived from its model (rule 6 makes every attribute typed).
2. **Box sections, in order, always present:** `== Attributes ==` (primitive fields only) · `== Properties ==` (getters) · `== Relationships ==` (0..1 ends: `+name: Target [0..1]`) · `== Collections ==` (0..n ends: `+name: Target [0..n]`) · `== Methods ==`.
3. **Relationship LINES with ends labelled:** every relationship whose target box is in the diagram is ALSO drawn as a line, the far end carrying **role name + multiplicity** (`Source --> "parent 0..1" Target`, `Source --> "children 0..n" Target`); containment as composition. Applies to class/graph and component diagrams.
4. **Dependency lines say what they are:** LEFT `centre -left-> n : uses`; RIGHT `centre <-right- n : usedBy`.
5. **Thinglish relationships are `ValueOfType | null`:** an empty association is `null`, **never `undefined`**; `isEmpty` ≡ `=== null`; `null` is an object. TS `parent: Tree | null = null`, interface `abstract get parent(): Tree | null`, ES2020 `parent = null`, Thing dialect `relationship parent: Tree | null`. A collection is never null — empty = `[]`.
7. **EAM layers stack vertically — layer 1 at the BOTTOM, layer 5 at the TOP** (Tron: *"make the eam layers stack above each other from 1 bottom to top 5 in the puml… layout link -down- to the next lower level"*). Within a component diagram the layer groups (already grouped by LAYER, PUML-plan Q1) are chained by **layout-only hidden links** `L5 -[hidden]down- L4 -[hidden]down- L3 …` between each present layer and the next lower present one (absent layers skipped, chain unbroken). PlantUML steers, it does not obey — so the proof is the RENDER, not the text.
6. **Every attribute is primitive:** a model-level `isPrimitive` (owned by `AttributeModel`/`M2AbstractAttribute`, one derived primitive set: `string`, `number`, `boolean`, `bigint`, string-literal unions); every attribute typed explicitly and `isPrimitive` true; anything else is a relationship/collection (Q1).
