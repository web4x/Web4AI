### Proven Recipe (tested 2026-03-10)

The JSONL file IS the session. Copy 1 file, join from the right directory:

```bash
# 1. Get agent's UUID
uuid=$(claudeCode session.id <pane>)

# 2. Build JSONL path
projectHash="-Users-Shared-Workspaces-AI-Claude"
jsonlPath="/Users/donges/.claude/projects/${projectHash}/${uuid}.jsonl"

# 3. SCP to target machine (push from source, not pull from target)
scp "$jsonlPath" <host>:"$jsonlPath"

# 4. On target: cd to project dir + join
# (via otmux send to the target pane on the remote machine)
otmux send <remote-pane> "cd /Users/Shared/Workspaces/AI/Claude" Enter
otmux send <remote-pane> "claudeCode join $uuid" Enter
```

### What we learned

| Finding | Detail |
|---------|--------|
| Session = 1 JSONL file | `~/.claude/projects/<project-hash>/<UUID>.jsonl` |
| Project hash = path with / → - | `-Users-Shared-Workspaces-AI-Claude` (same on both machines) |
| Session dir (subagents/) | Optional — not needed for resume |
| sessions-index.json | NOT needed — `claude --resume` finds the JSONL by UUID directly |
| Auth | Per-machine — `/login` needed on first use on target |
| Trust dialog | Appears on first run in a new directory — needs Enter to confirm |
| cwd matters | Must `cd` to project dir before `claudeCode join` |
| Push not pull | `scp` from source machine works, pull from target failed (path expansion) |

### Method Spec: `hiveMind.agent.restart.remote`

```
hiveMind agent.restart.remote <role> <host> <?pane>
```

Parameters:
- `role` — agent role name (e.g., product-owner)
- `host` — SSH config host name (e.g., MacStudio.native)
- `pane` — optional target pane on remote machine (default: resolve from registry)

Steps:
1. Resolve role → pane → UUID via `claudeCode session.id`
2. Build JSONL path from UUID
3. Verify JSONL exists locally
4. `scp` JSONL to `<host>:<same-path>`
5. Send `cd <project-dir>` to remote pane
6. Send `claudeCode join <UUID>` to remote pane
7. Verify session started (capture pane, check for Claude Code UI)

### Dependencies

- `ossh` or SSH config for host connectivity
- `claudeCode session.id` — to get UUID from pane
- `otmux send` — to send commands to remote panes
- Same project path on both machines (`/Users/Shared/Workspaces/AI/Claude`)
