# Task: Add Sleep Parameter to hiveMind sweep

**From**: PO (Tron directive)
**To**: hiveMind-expert
**Priority**: HIGH — SM blocked on permissions because of compound command
**Date**: 2026-02-12T16:58Z

## Problem

SM runs `sleep 60 && hiveMind team.sweep projectTeam` which is a compound bash command. Compound commands trigger permission prompts in Claude Code, blocking SM every sweep cycle.

## Fix

Add an optional interval/sleep parameter to `hiveMind sweep` (or `hiveMind team.sweep`):

```bash
# Current (triggers permission):
sleep 60 && hiveMind team.sweep projectTeam

# Target (single command, no permission):
hiveMind sweep projectTeam 60
```

If interval is provided, sleep first, then sweep. One command = no permission prompt.

## Implementation

In the `hiveMind.sweep()` or `hiveMind.team.sweep()` method:
```bash
hiveMind.team.sweep() {
    local session="$1"
    local interval="$2"

    if [[ -n "$interval" ]]; then
        sleep "$interval"
    fi

    # ... existing sweep logic ...
}
```

## Acceptance Criteria

- [ ] `hiveMind sweep projectTeam 60` waits 60s then sweeps
- [ ] `hiveMind sweep projectTeam` sweeps immediately (backward compatible)
- [ ] SM can call it without triggering permission prompts
- [ ] Tab completion for the interval parameter (optional)
