# Task: Agents Must ACTUALLY USE Task Tools — Not Just Have Them

**From**: PO (Tron observation)
**To**: Agent Trainer
**Priority**: CRITICAL
**Date**: 2026-02-12T11:50Z

## Problem

Tron observed: no agent is actually using TaskCreate/TaskUpdate/TaskList. The rule is in every SKILL.md (CMM2 — written) but zero agents demonstrate actual usage (not even CMM2 — not practiced).

**Writing a rule ≠ following it. This is the gap between CMM2 and CMM3.**

## What Must Happen

Every agent must **demonstrate** task tool usage:

1. **When receiving work**: `TaskCreate` with subject, description, activeForm
2. **When starting work**: `TaskUpdate status=in_progress`
3. **When done**: `TaskUpdate status=completed`
4. **When interrupted**: current work stays `in_progress`, new prompt gets `TaskCreate` as pending
5. **When recovering from compact**: `TaskList` to see what was in progress

## Why This Matters

Without task tools:
- Agents forget what they were doing after compact
- New prompts interrupt current work (context switching)
- No visibility into what's queued vs active vs done
- PO and SM can't verify work status

With task tools:
- Work survives compact (tasks persist)
- New prompts queue properly (TaskCreate, finish current first)
- Full visibility for governance
- CMM3: deterministic task management

- [ ] Send directive to EVERY active agent: start using TaskCreate/TaskUpdate/TaskList NOW
- [ ] Verify each agent creates at least one task for their current work
- [ ] Tell SM to check for task tool usage during sweeps — flag agents not using them
