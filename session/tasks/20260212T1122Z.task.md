# Task: SM — Enforce Task Queue Rule

**From**: PO
**To**: Scrum Master
**Priority**: HIGH
**Date**: 2026-02-12T11:22Z

## Directive

New team-wide rule: **Task Queue Rule**. During sweeps, verify agents are following it.

### Rule

When an agent receives a new prompt while busy:
1. They queue it as a future task (TaskCreate)
2. They finish current work first
3. Then pick up queued tasks

**Exceptions**: compact assistance, stop directives, permission approvals.

### SM Actions

- [ ] Add this rule to your monitoring checklist
- [ ] During sweeps, check if agents are interrupting work for non-urgent prompts
- [ ] Flag violations: agent switching tasks mid-work without queuing
- [ ] Add to your learnings.md as a sweep checkpoint
