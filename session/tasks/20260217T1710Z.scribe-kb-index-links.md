# Task: Add Markdown Links to Knowledge Base Index

**Assigned to**: woda-scribe
**From**: Tron
**Priority**: MEDIUM

## Objective

The knowledge base index (`session/knowledge-base/index.md`) should have proper markdown links pointing into the correct overview and detail files. Currently the W (What/Index) layer lists topics but doesn't link through to the O (Overview) and D (Details) layers.

## WODA Architecture Reminder

```
W (What/Index) → O (Overview) → D (Details) → A (Actions)
```

Each layer points to the next. The index (W) should link to overviews (O), which link to details (D), which link to actions (A).

## Deliverable

Update `session/knowledge-base/index.md` so every entry has a markdown link to its corresponding overview or detail file. For example:

```markdown
- [Team Delegation](overviews.md#team-delegation) → [Details](team-delegation.md)
- [Compaction Recovery](overviews.md#compaction-recovery) → [Details](compaction-recovery.md)
```

Use relative paths within the `session/knowledge-base/` directory.

## Acceptance Criteria

- [ ] Every index entry has a markdown link to its overview/detail file
- [ ] Links use relative paths and are valid
- [ ] WODA layering preserved (W→O→D→A, no layer contains next layer's content inline)
