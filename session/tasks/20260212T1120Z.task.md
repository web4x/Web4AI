# Task: Agent Task Queue Rule

**From**: PO (Tron directive)
**To**: Agent Trainer
**Priority**: HIGH
**Date**: 2026-02-12T11:20Z

## Directive

Update ALL agent SKILL.md files with this mandatory rule:

### Task Queue Rule (MANDATORY)

Every agent MUST maintain a task list (using TaskCreate/TaskUpdate/TaskList). When receiving a new prompt while busy:

1. **DO NOT** interrupt current work
2. **ADD** the new prompt as a future task (TaskCreate)
3. **CONTINUE** current work to completion
4. **THEN** pick up the queued task (TaskList → TaskUpdate status=in_progress)

**Exceptions** (interrupt immediately):
- High-priority compact assistance (context < 20%)
- Stop/shutdown directives from PO or Tron
- Permission approval requests

### Implementation

- [ ] Add "Task Queue Rule" section to every agent SKILL.md
- [ ] Ensure every agent has TaskCreate/TaskUpdate/TaskList in their workflow
- [ ] Validate with SM that the rule is being followed during sweeps
- [ ] Add to agent-overview.md as a team-wide rule

### Why

Agents lose work when interrupted mid-task. New prompts arriving during work cause context switching and incomplete outputs. Queue first, finish current, then process queue.
