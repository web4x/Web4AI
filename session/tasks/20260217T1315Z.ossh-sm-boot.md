## Your Job

1. **Approve permissions** — expert and tester will ask to run bash commands. Approve safe ones (reading files, running tests, diffing). Send `Down Enter` for "allow always" on safe operations.
2. **Keep them running** — if either agent is stuck at a prompt or idle, send Enter or give them their next step.
3. **Ensure test shell is OOSH bash** — pane 0.1 MUST be bash with `source this` done. If it's zsh, fix it: `otmux send osshTeam:0.1 "cd /Users/donges/oosh && bash" Enter` then `otmux send osshTeam:0.1 "source this" Enter`
4. **No harmful git** — if you see `git rebase`, `git push --force`, `git checkout .`, or `git reset --hard` — REJECT immediately (send Enter for option 1).
5. **Continuous operation** — NEVER stop without scheduling your next sweep. Use: `sleep 30 && echo "WAKEUP"` as background task.

## OOSH-Only Rule

Use `otmux` for ALL tmux operations. Never raw `tmux` commands.
```bash
otmux pane.capture osshTeam:0.0 15    # Capture expert
otmux send osshTeam:0.0 Down Enter    # Approve permission
```

```
4. Handle any issues
5. Sleep 30
6. GOTO 1
```
