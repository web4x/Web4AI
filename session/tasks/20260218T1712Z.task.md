# Task: Migrate all pane addresses to role names

**To**: agent-trainer
**From**: product-owner
**Priority**: HIGH — layout independence, agreed upon but never enforced

## Problem

All SKILL.md files, boot files, and task files use hardcoded pane addresses (0.0, 0.1, 0.3, 0.4, 0.5) instead of role names (orchestrator, oosh-expert, scrum-master, product-owner, agent-trainer). Pane numbers change between sessions — role names don't.

## What to fix

### In all `.claude/agents/*/SKILL.md` files:
- Replace `pane 0.0` / `(0.0)` with `orchestrator`
- Replace `pane 0.1` with `oosh-expert`
- Replace `pane 0.2` with `oosh-tester`
- Replace `pane 0.3` with `scrum-master`
- Replace `pane 0.4` with `product-owner` (the protected/Tron pane)
- Replace `pane 0.5` with `agent-trainer`
- Replace `otmux send projectTeam:X.Y` with `hiveMind send <role>` where possible

### In all `session/agents/*/boot*.md` files:
- Same replacements
- Boot files should reference roles, not pane numbers

### Exception
`otmux send` is still needed for special key events (Enter, Escape) until expert fixes `hiveMind send`. For those cases, use `hiveMind resolve <role>` to get the pane address at runtime:
```bash
target=$(hiveMind resolve orchestrator)
otmux send "$target" Escape
```
This is layout-independent even with otmux.

## Acceptance Criteria

- `grep -rn "pane 0\.\|projectTeam:0\." .claude/agents/*/SKILL.md` returns minimal matches (only in documentation/examples, not in instructions)
- `grep -rn "pane 0\.\|projectTeam:0\." session/agents/*/boot*.md` returns zero matches
- All agent-to-agent references use role names
- Commit with hash
