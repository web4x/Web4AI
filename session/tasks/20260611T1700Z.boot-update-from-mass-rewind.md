## Section to Add to Your boot.md

```markdown
## CONTEXT HEALTH — Self-Care (learned 2026-06-11)

### Self-save thresholds
- **80% used (~20% remaining)**: SAVE NOW. Commit context.md + learnings + worklist. Don't wait for SM flag.
- **90% used (~10% remaining)**: Save was your last chance. Stop dispatching new work.
- **0% (Context limit reached)**: Cannot save further (Rule 3). Only code/commits already in git survive. Chat-context lost.

### After-rewind checklist
1. State identity: pane title + role from your tmux pane (not session name)
2. Read boot.md, context.md, learnings.md
3. Check git: `git log --oneline -5` — verify your committed work survived
4. Verify reset depth: pane status bar must be clean (no "Context low")
5. If <30% used = deep reset (good runway). If >50% used = shallow reset (re-rewind sooner).
6. Self-report to your PO with state summary

### Code is safe in git, chat-context is not
- All commits survive any rewind/Tier-3/fork
- Uncommitted work dies on 0% or /clear
- DISCIPLINE: commit work in progress every 30 min when active, every 10 min when >70% used
```
