# Task: Action-to-Method Conversions

**From**: Orchestrator
**To**: developer
**Goal**: #5 (Software delivery)

## What

In `components/OOSH/dev.claude/`, find scripts that still use `action` as a parameter name in method dispatch and convert to `method`. This is the OOSH convention: `./scriptname method arg1 arg2`.

1. Check `this` kernel — how does it dispatch? Use `method` or `action`?
2. Find scripts using inconsistent naming (grep for `action` in dispatch logic)
3. Convert to consistent `method` naming
4. Run `test.suite run` on each changed script to verify no regressions
5. Commit changes with descriptive message

## Scope

Start with the most-used scripts: `oo`, `otmux`, `hiveMind`. Max 3 scripts this session.
