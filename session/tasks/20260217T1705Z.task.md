## Part 1: Knowledge Base — OOSH Parameter Naming Rule

Add to the knowledge base (`session/knowledge-base/`) and to the trainer's "Key Learnings to Propagate" section:

**Rule**: OOSH parameter names must be valid bash identifiers. No dashes, no special characters. Letters, numbers, underscores only. Cannot start with a number.

- BAD: `<name-or-pane>` → becomes `PARAM_name-or-pane` → bash crash
- GOOD: `<target>`, `<nameOrPane>`, `<pane_target>`

This applies to ALL method signatures in ALL OOSH scripts.

## Part 2: Migrate SKILL.md files from `otmux send <paneaddress>` to `hiveMind send <name>`

Many SKILL.md files still tell agents to use:
```bash
otmux send projectTeam:0.0 "message" Enter
otmux send projectTeam:1.2 "Task done" Enter
```

This is layout-dependent — if panes move, commands break. All SKILL.md files should use:
```bash
hiveMind send.enter orchestrator "message"
# or
hiveMind send.enter task-agent "Task done"
```

Search all 81+ SKILL.md files for `otmux send projectTeam:` patterns and replace with the `hiveMind send.enter <rolename>` equivalent.
