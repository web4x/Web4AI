# Task: Clean Up Task Files

## User Directive (verbatim)

> the project is becoming messy. especially tasks files. clean up... all task files need to end with ...task.md and be in a task folder and have a utc timestamp in the name. no description

## Rules

1. **Every task file** must match pattern: `{YYYYMMDD}T{HHMM}Z.task.md` (UTC timestamp, ends with `.task.md`)
2. **All task files** must live in `session/tasks/`
3. **No description in the filename** — the title goes INSIDE the file, not in the name
4. **Rename every existing file** to match the new pattern
5. Use the file's git creation date (or modification date) for the timestamp
6. **Update any references** in other files that point to old task filenames (SKILL.md files, context files, etc.)
7. Delete duplicates or clearly obsolete files (completed one-off tasks from days ago)
