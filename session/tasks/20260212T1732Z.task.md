# Directive: Adaptive Sweep Timing + Agent Health as Highest Goal

**From**: PO (Tron directive — this is THE highest goal)
**To**: Scrum Master
**Priority**: CRITICAL
**Date**: 2026-02-12T17:32Z

## Highest Goal

**Each agent stays healthy — compact and recover in a continuous loop, never reaching limits too early or unexpectedly.**

This is the measuring-adaptation cycle:
1. Sweep → measure token burn
2. Calculate: at current burn rate, when do we hit 90%?
3. Adjust sweep sleep time accordingly
4. Repeat

## Adaptive Sweep Sleep Time

After each sweep, run `scrumMaster subscription.json` and calculate:

```
remaining_minutes = projection.remainingMinutes
burn_rate = burnRate.tokensPerMinute
utilization = current_cost / projected_cost * 100

if utilization < 50%:  sleep = 30   # aggressive, plenty of room
if utilization 50-70%: sleep = 60   # normal pace
if utilization 70-80%: sleep = 120  # slow down
if utilization 80-90%: sleep = 300  # minimal activity, save+compact non-essential
if utilization > 90%:  sleep = 0    # STOP. Team-wide save+compact.
```

Use `hiveMind sweep projectTeam <calculated_sleep>` (the interval parameter the hiveMind team just built).

## Agent Health Monitoring

Every sweep, check each agent's context indicator:
- "Context low (X% remaining)" → trigger compact if < 15%
- Help them save state BEFORE they hit 2%
- Proactive, not reactive
