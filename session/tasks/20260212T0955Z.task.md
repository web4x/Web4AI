# Task: Validate Migration and Remove Outdated Agent Files

## What

Old agent files are scattered in `session/` and `session/agents/` (flat). New files should be in `session/agents/<role>/` (subdirectories). Before removing the old files, verify NOTHING was lost.

## Process (per agent, one at a time)

For EACH agent that has old files:

1. **Read the old file** (e.g. `session/woda-scribe.learnings.md`)
2. **Read the new file** (e.g. `session/agents/woda-scribe/learnings.md`)
3. **Compare** — is all content from the old file present in the new file?
4. **If anything is missing** — merge the missing content into the new file
5. **Remove the old file** only after confirming nothing was lost
6. **Commit per agent**: `git add session/agents/<role>/ && git rm <old-files> && git commit -m "Migrate <role> files: validated and cleaned"`

## Rules

- **Read before removing** — NEVER delete an old file without reading it first
- **Compare line by line if needed** — content matters, not just file existence
- **Merge missing content** — if old file has items the new file doesn't, add them
- **Commit per agent** — one commit per agent, not one giant commit
- **Add this task to your learnings** — "always validate before removing old files"
