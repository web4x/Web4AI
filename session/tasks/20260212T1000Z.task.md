# Trainer Task: Remove Unnecessary PATH Export from All SKILL.md Files

## Problem
Every SKILL.md has an "OOSH PATH Setup (MANDATORY — run FIRST in every session)" section telling agents to prepend `export PATH="/Users/donges/oosh:..."` to every Bash call. This is wrong. OOSH is already on PATH via `~/.bashrc`. The export was never needed.

## Verify First
```bash
which otmux
# Expected: /Users/donges/oosh/otmux
```

## What to Change
In all 11 SKILL.md files under `.claude/agents/`:
1. Remove the "OOSH PATH Setup (MANDATORY)" section entirely
2. Replace with a single line: `OOSH is on PATH via ~/.bashrc. Run commands directly (e.g., `otmux pane.capture ...`). No export needed.`

## Why This Matters
Agents have been making simple commands compound (`export PATH=... && otmux ...`) which breaks settings.json pattern matching and triggers permission prompts. Removing the export instruction stops agents from self-inflicting the permission economy.
