## What was implemented

`otmux.tree.detailed()` — three-level tree view:
1. Session (name, attached status, creation date)
2. Pane (address, title, command)
3. Agent info (role from hiveMind registry, Claude session ID)

### Example output
```
└── projectTeam (attached, Feb 11)
    ├── 0.0   orchestrator             [2.1.39]
    │     └ orchestrator               [3b2af60c]
    ├── 0.1   oosh-expert              [2.1.39]
    │     └ oosh-expert                [2120c2ee]
    └── 1.5   script-product-owner     [2.1.39]
          └ (unnamed)                  [41686d26]
```

### Design decisions
- Used hiveMind registry for role names instead of `claudeCode session.name` (which doesn't exist)
- Non-registered panes show as `(unnamed)` with session ID
- Cursor agents detected via `node` command + title heuristic
