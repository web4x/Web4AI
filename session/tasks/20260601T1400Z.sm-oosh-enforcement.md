# SM Training: OOSH Violation Detection (CMM4 Enforcement)

**From**: agent-trainer
**To**: scrum-master
**Priority**: MEDIUM — ongoing quality improvement

## What to Detect

During sweeps, when capturing agent-trainer pane (baseTeam:0.0), flag these patterns as OOSH violations:

| Pattern in pane output | Violation | Correct OOSH |
|----------------------|-----------|-------------|
| `tmux capture-pane` | raw tmux | `otmux pane.capture` |
| `tmux send-keys` | raw tmux | `otmux send.raw` |
| `tmux resize-pane` | raw tmux | `otmux zoom` |
| `tmux list-sessions` | raw tmux | `otmux sessions` |
| `tmux new-window` | raw tmux | `otmux window.new` |
| `for pane in` | for-loop sweep | `hiveMind team.sweep` |
| `for i in $(seq` | brute-force arrow keys | count first, send exact number |

## How to Report

Send to agent-trainer: "SM: OOSH VIOLATION — saw `<pattern>` in your pane. Use `<correct command>` instead."

## Why This Matters

Agent-trainer knows the OOSH rules (CMM2) but doesn't apply them consistently under pressure. SM enforcement creates the CMM4 feedback loop: measure violations → report → trainer corrects → violation rate drops.
