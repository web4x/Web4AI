# Task: Improve teams.migrate for cross-machine fork + JSONL transfer

## W(hat)

`teams.migrate` restores the tmux layout on a remote machine but agents can't actually work because:
1. JSONL session files are NOT transferred — `claudeCode join` fails with "No conversation found"
2. Uses `claudeCode join` instead of `claudeCode fork` — causes same-UUID rate-limit conflict
3. No model compatibility check — MacStudio had `opus[1m]` in settings.json which blocked ALL API calls

**Proven today**: changing `opus[1m]` to `opus` in `~/.claude/settings.json` + scp JSONL + `claudeCode fork` = fully working agent on MacStudio with identity + context preserved.

## D(etails)

### F1: Transfer JSONL files

After step 2 (transfer config) and before step 5 (restore), add JSONL transfer:

```bash
# Between config transfer and restore:
echo "Transferring session files to $host..."
local claudeProjectsDir="$HOME/.claude/projects"
local transferCount=0
while IFS='|' read -r sess addr role uuid title; do
  [[ "$sess" == "#"* ]] && continue
  [ -z "$uuid" ] && continue
  # Find JSONL
  for dir in "$claudeProjectsDir"/*/; do
    if [ -f "${dir}${uuid}.jsonl" ]; then
      local remotePath="${dir}${uuid}.jsonl"
      scp "$remotePath" "${host}:${remotePath}" 2>/dev/null && transferCount=$((transferCount + 1))
      break
    fi
  done
done < "$snapfile"
echo "Transferred $transferCount JSONL files"
```

### F2: Use fork instead of join for cross-machine

In `teams.restore` line 1524, when running on a remote machine (or when `--fork` flag given):

```bash
# Current (line 1524):
"$OOSH_DIR/otmux" send "$pane_target" "claudeCode join $uuid" Enter

# New (when fork mode):
"$OOSH_DIR/otmux" send "$pane_target" "claudeCode fork $uuid" Enter
```

Add a `--fork` flag or auto-detect cross-machine by checking if the JSONL was recently scp'd.

### F3: Model compatibility check

In `teams.migrate` prereqs section, add:

```bash
# Check model setting on remote — opus[1m] not available on all subscriptions
local remoteModel
remoteModel=$("$OOSH_DIR/ossh" exec "$host" 'cat ~/.claude/settings.json 2>/dev/null | grep -o "opus\[1m\]"')
if [ -n "$remoteModel" ]; then
  warn.log "Remote has opus[1m] model — changing to opus (200k)"
  "$OOSH_DIR/ossh" exec "$host" 'echo "{\"model\": \"opus\"}" > ~/.claude/settings.json'
fi
```

### F4: teams.restore --fork flag

Add optional flag to `teams.restore`:

```bash
hiveMind.teams.restore() # <?snapshotFile> <?--fork> # restore teams from snapshot
```

When `--fork` is passed, use `claudeCode fork` instead of `claudeCode join`.
`teams.migrate` should always pass `--fork` since it's cross-machine by definition.
