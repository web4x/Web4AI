## The Three Shells — Know the Difference

| Shell | What it is | OOSH? | Completions? |
|-------|-----------|-------|-------------|
| **zsh** | macOS default login shell (`/bin/zsh`). What you get when you open Terminal. | NO | zsh has its OWN completion system (`compdef`, `_arguments`). OOSH does NOT use it. |
| **bash** | Bourne Again Shell. OOSH is built on bash. | YES — but only when OOSH is sourced | Only when `c2` completions are registered via bash's `complete` builtin. |
| **OOSH bash** | A bash shell where OOSH's `this` kernel is sourced and `c2` completions are active. | YES | YES — `complete -F` registers OOSH method completions. |

## How OOSH Works (fundamentals you MUST know)

### 1. OOSH is NOT "bash scripts". It's a framework.

OOSH is a pseudo-OOP layer on top of bash:
- **Script file** = Class (e.g., `ossh`, `user`, `config`)
- **Functions** = Methods (e.g., `ossh.login()`, `ossh.config.get()`)
- **`this`** = The kernel — it dispatches `./scriptname method` to `scriptname.method()`
- **`c2`** = The completion system — it reads method signatures and registers bash completions

### 2. How `c2` completions work

When OOSH is sourced in bash, `c2` does this:
```bash
complete -F _oosh_complete ossh    # Register ossh for tab completion
complete -F _oosh_complete user    # Register user for tab completion
```

When you type `ossh login [Tab]`, bash calls `_oosh_complete` which:
1. Looks at `ossh.login()` method signature: `# <sshConfigHost>`
2. Finds `ossh.login.completion()` or `ossh.parameter.completion.sshConfigHost()`
3. Calls that function to generate completion candidates
4. Returns them to bash's readline

**This ONLY works in bash.** zsh's `complete` doesn't exist — you get `command not found: complete`.

### 6. The `ossh.login.completion()` function

```bash
ossh.login.completion() {
  ossh.config.get.completion "$@"
}
```

This delegates to `ossh.config.get.completion()` which reads SSH config hosts. If this doesn't work, trace:
1. Does `ossh.config.get.completion` exist? (`type ossh.config.get.completion`)
2. Does it return output? (`ossh.config.get.completion`)
3. Does `c2` know about ossh? (`complete -p ossh`)
