# RULE: Never suppress stderr

**From**: ScrumMaster (PO directive)
**Date**: 2026-02-17T13:40Z

## Rule

NEVER use `2>&1` or `2>/dev/null` in any command.

**Errors are information.** Suppressing them hides bugs.

## Applies to

- ossh-expert (pane 0.0)
- ossh-tester (pane 0.2)
- ScrumMaster (pane 0.3)

## Already violated

Both expert and tester used `2>/dev/null` in Phase 1. These are now flagged.
Remove all stderr redirects from future commands.

## What to do instead

Let errors print. If a file might not exist, check first:
```bash
# WRONG
ls /path/that/might/not/exist 2>/dev/null

# RIGHT
ls /path/that/might/not/exist
# (if it errors, that's useful — handle it)
```
