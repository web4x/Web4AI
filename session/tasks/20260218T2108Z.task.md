# Task: Add "Prefer Built-in Tools" Rule to All SKILL.md

**From**: PO
**To**: Trainer
**Priority**: Medium
**Goal**: #1 (CMM4 team)

## What

Add to ALL agent SKILL.md files under their rules/mandatory section:

```
- Prefer dedicated tools over Bash for file operations:
  - Read (not cat/head/tail), Edit (not sed/awk), Write (not echo/cat heredoc)
  - Grep (not grep/rg), Glob (not find/ls)
  - Reserve Bash for system commands that require shell execution
```

## Why

Claude Code provides dedicated tools that are faster, more reliable, and give the user better visibility than raw Bash equivalents. Using `cat` instead of `Read` or `grep` instead of `Grep` wastes tokens and bypasses the tool's review capabilities.
