## What is sshDir?

`sshDir` is an optional parameter on SSH-related methods that overrides the default `~/.ssh` base directory. This enables:
- Managing SSH keys in non-standard locations
- Multi-machine SSH configurations (different .ssh dirs per target)
- Identity isolation (separate key stores per project/org)

### Key helper functions restored:
- `private.get.sshDir "$1"` — resolves sshDir parameter, defaults to `~/.ssh`
- `private.detect.ssh.key.type "$dir"` — auto-detects ed25519/rsa/ecdsa key type
- `private.detect.ssh.key "$dir"` — finds the actual key file
