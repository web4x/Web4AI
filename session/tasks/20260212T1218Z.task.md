## Tron's Clarification on script-product-owner

The `script-product-owner` template is NOT just an ownership contract. It's a **specialist delegate pattern**:

- One specialist per OOSH script (or group of related scripts)
- Each specialist is 100% aware of their script's internals, history, patterns, edge cases
- PO and agent trainer invoke them for precise planning and coordination
- They coordinate development and testing more precisely than a generalist ever could

### Why

You can't remember everything about everything. Instead of one expert trying to know all scripts, you create specialists:

```
PO (governance)
  ├── hiveMind specialist  ← knows everything about hiveMind
  ├── claudeCode specialist ← knows everything about claudeCode
  ├── otmux specialist     ← knows everything about otmux
  ├── config specialist    ← knows everything about config
  └── ... one per script that needs deep knowledge
```

### Key Rule

**PO and agent trainer are ALWAYS allowed to create more specialists.** No need to ask permission. When a script grows complex enough to need dedicated knowledge, spawn a specialist.
