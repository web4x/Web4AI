# Task: Add claudeCode fork method for cross-machine session migration

## W(hat)

Add `claudeCode fork <UUID>` method that wraps `claude --resume <UUID> --fork-session`. This is critical for cross-machine agent restart — fork creates a new session ID while preserving full conversation history, avoiding session ID conflicts.

## O(verview)

| Item | Detail |
|------|--------|
| New method | `claudeCode fork <UUID>` — resume with new session ID |
| Why fork? | Same session ID on two machines = rate limit. Fork = new ID, same context. |
| Proven | Tested on MacStudio: `claude --resume c2775135 --fork-session` → new UUID `309b535b`, full PO context preserved |
| Color issue | Raw `claude` on MacStudio had color issues — `claudeCode` wrapper applies color fixes |

## D(etails)

### Method spec

```bash
claudeCode.fork() # <sessionId> # fork session with new ID, preserving conversation
{
  local sessionId="$1"
  if [ -z "$sessionId" ]; then
    error.log "Usage: claudeCode fork <sessionId>"
    return 1
  fi
  # Apply same color/env fixes as claudeCode.join
  # Then:
  $CLAUDE_CMD --resume "$sessionId" --fork-session
}
```
