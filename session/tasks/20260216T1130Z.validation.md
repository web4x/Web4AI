## Notes (not blocking)

**NOTE 1: Object.verb public API wrappers removed**
The pre-restore current version had an "OBJECT.VERB PUBLIC API" section with wrappers like `ossh.key.push()`, `ossh.dir.pull()`, `ossh.url.get()`, etc. These followed OOSH naming conventions (object.verb). Expert's restoration reverted to the restored version's verb.object naming (`ossh.push.key`, `ossh.pull.dir`, `ossh.get.url`). The wrappers are gone.

This may break any code or documentation referencing the object.verb names. Not blocking since the verb.object names are the original API, but worth noting for future OOSH naming standardization.

**NOTE 2: Empty-string id parameter quirk**
`ossh get.public.id "" "$HOME/.ssh"` doesn't reach the sshDir param because `[ -n "" ]` is false and shift doesn't fire. This is the same behavior as the restored version — pre-existing, not a regression.
