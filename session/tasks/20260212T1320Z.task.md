## Discovery

`ccusage` (v18.0.5) is available via `npx` and provides exactly the subscription data we need.

### Key Command

```bash
npx ccusage blocks --active --json
```

Returns: block times, token counts, cost USD, burn rate (tokens/min), projected totals, time remaining.

### Also Available

```bash
npx ccusage statusline          # Compact one-liner for status bars
npx ccusage daily --json        # Daily usage
npx ccusage session --json      # Per-session breakdown
npx ccusage blocks --live       # Real-time tracking
```

## What To Build

### 1. New OOSH method: `scrumMaster subscription`

Calls `npx ccusage blocks --active --json`, parses the output, and displays:

```
Subscription Status:
  Block: 14:00-19:00 UTC (ACTIVE)
  Tokens: 3.3M / 228 min remaining
  Burn rate: 47k tokens/min
  Cost: $5.02 (projected: $21.30)
  Alert: [OK | WARNING 80% | CRITICAL 95%]
```

### 2. New OOSH method: `scrumMaster subscription.json`

Returns raw JSON for dashboard integration.

### 3. Alert threshold

If burn rate projects hitting limit before block ends, output WARNING.
SM can call this in sweep cycles and alert PO.

### 4. Dashboard integration

`scrumMaster dashboard` should include subscription data from `scrumMaster subscription.json`.
