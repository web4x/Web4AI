# Task: Rename Metrics Files to scenario.env Convention

**From**: PO (Tron-confirmed)
**To**: Expert (when capacity allows)
**Priority**: NORMAL
**Date**: 2026-02-12T16:52Z

## Problem

Metrics files in `session/metrics/` use `.env` suffix but should follow the OOSH web4 config pattern: `*.scenario.env`.

Current: `subscription.20260212T151354Z.env`
Target: `subscription.20260212T151354Z.scenario.env`

This applies to ALL metrics files: `subscription.*.env`, `velocity.*.env`, `context.*.env`, agent metrics, etc.

## Implementation

1. In `scrumMaster subscription` (and any method that writes to `session/metrics/`): change output filename pattern from `*.env` to `*.scenario.env`
2. Rename existing files: `for f in session/metrics/*.env; do mv "$f" "${f%.env}.scenario.env"; done`
3. Update any code that reads these files to expect `*.scenario.env` glob

## Acceptance Criteria

- [ ] New metrics files written as `*.scenario.env`
- [ ] Existing files renamed
- [ ] No breakage in `scrumMaster subscription` or `scrumMaster dashboard`
