# Task: All Agents Must Sync Internal Tasks to Permanent Files

**From**: PO (Tron directive)
**To**: Agent Trainer → ALL agents
**Priority**: HIGH
**Date**: 2026-02-12T11:55Z

## Problem

Internal tasks (TaskCreate/TaskUpdate/TaskList) are volatile — they die on compact. Permanent files (backlog.md, context.md) survive. Agents must keep both in sync.

## Rule

- **TaskCreate** = short-term tracking (what am I doing NOW, what's next)
- **backlog.md** = long-term tracking (all open/done work, survives compact)
- **context.md** = recovery state (current goal, pending items, survives compact)

**Before compact**: sync internal tasks → backlog.md + context.md
**After compact**: read backlog.md → TaskCreate for pending items
