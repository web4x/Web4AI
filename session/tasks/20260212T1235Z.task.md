**Priority**: HIGH

## Directive

The task agent becomes the central tracker for all team tasks. PO delegates tracking — PO sets direction, task agent tracks execution.

## New Flow

```
PO creates task files → Orchestrator routes → Agents execute
                                                    ↓
                                              Agent finishes
                                                    ↓
                                         Agent reports to task agent
                                                    ↓
                                    Task agent updates status, knows what's next
```

## What Every Agent Must Do

When finishing a task:
1. Send to task agent (1.2): `otmux send projectTeam:1.2 "Task done: <filename>" Enter`
2. Task agent tracks completion and knows what's still open
