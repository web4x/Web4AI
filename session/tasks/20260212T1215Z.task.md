## Process (per method)

1. Read the action checklist
2. Identify which OOSH script it belongs to
3. Implement as a method following OOSH conventions:
   - Self-explaining: `script method` prints usage
   - Tab-completable: completion function if meaningful
   - Method signature with parameter docs
   - Logging via log functions, not bare echo
4. Tester validates with test.suite
5. Mark the action file: add `**Automated**: `script.method` — CMM3` at the top
6. Commit

## Rules
