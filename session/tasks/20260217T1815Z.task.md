# Task: Reorganize Agent Folder Structure

**Assigned to**: agent-trainer
**From**: Tron
**Priority**: HIGH

## Current Problem

Boot files are in a separate folder `session/boot/` while agent state lives in `session/agents/<role>/`. This is fragmented — two places to look for agent files.

## New Structure

Each agent gets ONE folder under `session/agents/<role>/` containing everything:

```
session/agents/<role>/
├── boot.md          ← moved from session/boot/<role>.md
├── context.md       ← already here
├── learnings.md     ← already here
├── backlog.md       ← already here
├── SKILL.md         ← symlink → .claude/agents/<role>/SKILL.md
└── MEMORY.md        ← symlink → .claude/agents/<role>/MEMORY.md (if exists)
```

## Steps

### 1. Move boot files
Move each `session/boot/<role>.md` → `session/agents/<role>/boot.md`

### 2. Create symlinks for SKILL.md
For each agent folder in `session/agents/<role>/`, create:
```bash
ln -s /Users/Shared/Workspaces/AI/Claude/.claude/agents/<role>/SKILL.md session/agents/<role>/SKILL.md
```

### 3. Create symlinks for MEMORY.md (if applicable)
Same pattern — link to `.claude/agents/<role>/MEMORY.md` if it exists.

### 4. Update all references
All SKILL.md files, boot files, context recovery sections, and the boot hook that reference `session/boot/<role>.md` must be updated to `session/agents/<role>/boot.md`.

### 5. Remove session/boot/ folder
After all files moved and references updated, delete the old `session/boot/` directory.

### 6. Update unknown.md handling
The default `session/boot/unknown.md` should become `session/agents/unknown/boot.md` or better yet — the boot hook should error instead of defaulting to a useless file.

## Acceptance Criteria

- [ ] All boot files moved to session/agents/<role>/boot.md
- [ ] SKILL.md symlinks created in each agent folder
- [ ] All references updated (SKILL.md files, hooks, knowledge-base)
- [ ] session/boot/ folder removed
- [ ] Boot hook updated to use new paths
- [ ] Committed with hash
