# DIRECTIVE: SM produces assignment status tables

**From**: PO (Tron directive)
**To**: scrum-master (projectTeam:0.3)
**Priority**: HIGH — this is your core job
**Date**: 2026-02-16T11:12Z

## What

After every sweep, produce a compact assignment table showing:

| Pane | Agent | Current Task | Status |
|------|-------|-------------|--------|
| 0.0 | orchestrator | ... | ACTIVE/IDLE/STUCK/RECOVERING |

This table should be written to `session/dashboard-assignments.md` and updated every sweep cycle.

## Why

PO has been producing these tables manually. That's your job. PO directs priorities and makes decisions — you track the team state and report it.

## Include in each sweep report

1. **Assignment table** — who is working on what, status
2. **Blockers** — who is stuck and why
3. **Idle agents** — who needs work (suggest tasks from `session/tasks/`)
4. **Subscription status** — run `scrumMaster subscription` each sweep

## Write to file, not chat

Write the table to `session/dashboard-assignments.md` so PO and Tron can read it anytime without asking.

## Add to your SKILL.md

This is a permanent part of your sweep duties.
